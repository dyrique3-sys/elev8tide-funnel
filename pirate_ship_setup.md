# Pirate Ship — Setup Sheet (ELEV8TIDE)

**What it is:** free software, no monthly fee — you only pay for postage, at the deepest USPS/UPS discounts available (cheaper than retail). Perfect for a small, discreet store.

## Nashay does (≈10 min)
1. Sign up at **pirateship.com** (free, no credit card to start).
2. **Ship-from address:** her business address — **3150 SW 145th Ave, Miramar FL 33027** (or the Brickell/registered address if she prefers packages not tie to home).
3. Connect payment for postage (card or PayPal — just funds labels).
4. (Optional) connect the store later; for now she creates labels manually per order — fine at this volume.

## Per-order flow (manual, matches the P2P model)
Order lands → payment confirmed → she opens Pirate Ship → "Create a label" → paste buyer's name + address (from the checkout form) → pick box size + weight → buy label → print → tracking # → send tracking to buyer (the order-confirmation email covers this).

## Package presets to decide NOW (so labels are 1-click)
| Preset | Use for | Est. weight | Box |
|---|---|---|---|
| **Single vial** | 1 product | 4–6 oz | small bubble mailer / 4x4x4 |
| **Stack (2–3)** | goal stacks | 8–12 oz | 6x4x4 box |
| **Complete Stack** | flagship | 14–18 oz | 7x5x5 box |

> Weigh one real packed order on a kitchen scale to lock exact weights — then every future label auto-fills.

## Discreet shipping (she asked for this)
- Plain box, no branding/product name on the outside.
- Generic return name (e.g. "E8 Supply" or just the address).
- USPS Ground Advantage or Priority = tracked + affordable.
